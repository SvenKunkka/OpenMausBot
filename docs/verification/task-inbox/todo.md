## 16:11 补充验收

- 在真实 Chrome 中，旧任务 A 已超出最新 200 条消息。注入一次历史请求失败，界面提示错误且 A 仍未看。用回车重试后，A 的原回复进入可见区域，B 仍未看。页面刷新后只剩 B 的角标。随后删除该测试会话，两个任务均从列表及 SQLite 移除，另一会话保留。
